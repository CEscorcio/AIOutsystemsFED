DropdownButton

A split button: the left part runs the default action (an OnClick event, or a link when Url is set) and the chevron opens a menu of other actions that the screen puts in the Menu placeholder.

Open with ?test=1 to run the checks. Each cell mirrors the Block: the mount (block class + ExtendedClass) holding the MenuContainer with the screen's Links.

Click a button or a menu item.
